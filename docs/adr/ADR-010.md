# ADR-010: Deterministic UUIDv5 point IDs

Status: Accepted

## Context
Qdrant point IDs must be unsigned integers or UUIDs. Ingestion must be idempotent and
resumable.

## Decision
Point ID = `UUIDv5(namespace, passage_id)`. The original `passage_id` is kept in payload.

## Consequences
- Same passage -> same point -> idempotent upsert and crash-safe resume.
