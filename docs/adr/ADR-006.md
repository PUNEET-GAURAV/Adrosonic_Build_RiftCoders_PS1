# ADR-006: Cross-encoder reranker behind a latency budget

Status: Accepted

## Context
Reranking is the single biggest precision lever (bonus objective), but a cross-encoder adds
CPU latency that could break the p95 < 300 ms gate.

## Decision
Use `cross-encoder/ms-marco-MiniLM-L-6-v2` on the top-30 fused candidates, only in
`hybrid_rerank` mode, with a latency-budget guard that flags `degraded` if the budget is
exceeded. The official p95 is measured on `hybrid` (no rerank), so rerank never threatens
the gate.

## Consequences
- Rerank lift is measured and reported separately from the latency-critical hybrid number.
