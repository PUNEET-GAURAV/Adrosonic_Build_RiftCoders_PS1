# ADR-005: Filter inside every prefetch (true pre-retrieval)

Status: Accepted

## Context
FR-4 requires filters applied pre-retrieval at the database level, not post-retrieval.

## Decision
Translate the domain `Filters` into a Qdrant `Filter` and pass it into **each** dense and
sparse query, so a selective filter still returns a full top-k.

## Consequences
- Proven by a selective-filter test (a filter matching ≈0.1% of the corpus returns a full
  top-5, all matching). Post-filtering a fixed top-k could not guarantee this.
