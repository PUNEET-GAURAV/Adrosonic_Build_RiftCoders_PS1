# ADR-011: Cache keyed on index_version

Status: Accepted

## Context
A query cache must never serve stale results after a live upsert/delete.

## Decision
Cache key includes query, mode, filters, user groups and `index_version`. Every upsert or
delete bumps `index_version`, invalidating affected entries.

## Consequences
- Proven by a cache-invalidation test. Stale/leaked results after live updates are impossible.
