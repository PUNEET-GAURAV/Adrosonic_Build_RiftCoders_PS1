# ADR-007: FastAPI service + Streamlit UI

Status: Accepted

## Context
Need a query interface (FR-6) and a reusable service that the benchmark runner, eval
harness and (future) MCP server can all call.

## Decision
FastAPI owns the retrieval/answer/documents endpoints; Streamlit is a thin HTTP client of
that API. Alternatives: Streamlit-only (not reusable), Next.js (slower to build for this
window).

## Consequences
- "The API is the product": the UI, benchmark and eval are all clients of one service.
- The generated OpenAPI spec is a natural starting point for a Power Platform connector.
