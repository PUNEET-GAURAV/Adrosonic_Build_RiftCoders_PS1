# ADR-012: Groq free tier with extractive fallback

Status: Accepted

## Context
The brief requires free-tier only (paid key = disqualification). Grounded answers and
LLM-judged RAGAS need an LLM, but the repo must run with no key at all.

## Decision
Use the Groq free tier for generation and LLM-judged RAGAS (verify the current free model
list at build time). Every LLM call has a graceful fallback: extractive answers for
generation, non-LLM metrics for evaluation.

## Consequences
- The repo runs with no key; adding a free Groq key upgrades answers and judged metrics.
