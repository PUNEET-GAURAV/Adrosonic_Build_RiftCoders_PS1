# ADR-003: BGE-small embeddings

Status: Accepted

## Context
The brief requires a HuggingFace sentence-transformer model. Need good quality per
CPU-millisecond on a laptop.

## Decision
Use `BAAI/bge-small-en-v1.5` (384-d) via sentence-transformers, with the BGE query
instruction prefix on queries only. Alternatives: all-MiniLM-L6-v2 (slightly weaker),
bge-base (heavier).

## Consequences
- 384-d keeps RAM at ~154 MB per 100k raw vectors.
- If p95 is blown by the encoder, fall back to MiniLM-L6 or an ONNX backend (ADR revisit).
