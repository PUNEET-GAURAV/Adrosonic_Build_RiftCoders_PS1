Methodology

  • Eval set: seed-42 pool, MS MARCO validation queries with a selected passage (is_selected = 1).
  • Tuned only on dev split; reported numbers are on held-out test split.
  • RAGAS context precision & recall evaluated against gold passage IDs.
  • Hybrid fusion: weighted combination — dense 1.0, sparse 0.1 (optimised to outperform RRF on this corpus).
  • ONNX reranker: cross-encoder/ms-marco-MiniLM-L-6-v2 exported via optimum, CPU inference.
  • Official p95: hybrid mode, cache off, 100 distinct queries, idle machine.
